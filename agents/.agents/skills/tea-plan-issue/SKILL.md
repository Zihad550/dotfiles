# Instructions
1. Use the `tea` CLI to get issue information:
```bash
tea issue <issue-id> 
```
2. Create a step by step plan to fix the issue.
3. Don't hesitate to ask the user for information if you are uncertain about something (issue id).

# Requirements
1. Get issue informations.
2. Create plan to fix issue.
